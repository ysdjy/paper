## Replicate independence — REAL but modest; label-invariant (the one caveat)
Two layers (all-cell median is polluted by clean-fail cells whose `final=0`):
- **Continuous**: success-cell within-block final-pos SD **median 2.81e-3, max 7.21e-3** — a real,
  nuisance-driven spread **≈4.7× the damping float noise (6e-4)**. So the 3 blocks are genuine independent
  draws, **not** the damping stage's technical repeats.
- **Label**: **0 success-label flips** — every cell is 3/3 or 0/3.

Verdict: `replicate_continuous_independent = False` only because the median (2.81e-3) sits just **below**
the pre-set bar of **3e-3 (5× float noise, fixed before observing the value)**, and there are no label
flips. So replicate independence is **borderline NOT MET**.

**Diagnosis (per the exploratory exit contract):** not a bias-range problem (the bias effect is strong and
monotone across ±0.04) and not degenerate (45/105). The cause is **nuisance amplitude vs a sharp success
edge**: the block nuisance (robot arm-joint perturbation + ±5 mm target jitter) moves the final position
modestly but never crosses the grasp-tolerance boundary, so it cannot flip a success label. Robot-joint
perturbation is largely **pose-invariant** to a handle-frame grasp (the closed-loop IK converges to the
same grasp), so enlarging it will not help.

## Recommendation for the next exploratory iteration (NOT applied; not tuned to a result)
The core science is strongly established: **a hidden handle calibration bias reorders which grasp offset
is optimal (best = −bias), with no robust generalist and a large VSI (~0.52)** — the decision-value signal
the damping stage lacked. The only gap is label-level replicate variance. For a **v3 exploratory** grid
(pre-registered before any confirmatory run):
1. Add a small **per-block action/control noise on the grasp landing** (or widen target jitter), sized to
   straddle the ±0.02 success edge, so near-boundary cells flip across blocks — genuine label-level
   replicate variance. Record its distribution + seed.
2. Do **not** enlarge the robot-joint perturbation (pose-invariant, no effect on the label).
3. Keep the block-nuisance machinery, matched grid, and 3 blocks (all verified clean here).
