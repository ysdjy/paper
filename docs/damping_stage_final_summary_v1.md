## Confirmed findings

### 1. Prediction — HOLDS (exploratory, sim-only)
- The hidden per-session damping is **recoverable from probe history**: nearest-centroid classification of
  the damping level from probe features reaches **acc 1.00** (chance 0.33); probe P1 final-position spread
  is monotone 0.266 / 0.080 / 0.039 across D = 3 / 20 / 40.
- Probe history **improves candidate-outcome prediction**, capacity-matched: **AUROC 0.536 → 0.714**,
  Brier 0.276 → 0.210, error-MAE 0.084 → 0.073.
- Scope caveat (confirmed by all three): only **3 damping states**, cleanly separated and present in every
  fold → this is 3-way lookup, **not** generalization to unseen damping; sim-only, no domain randomization.

### 2. Ranking / landscape reorder — HOLDS
- Damping **reorders the candidate landscape**: aggressive candidates swing **> 1.1 utility** across
  damping; the physical mechanism is `HANDLE_DETACHED` (aggressive long-carrot pull rips the handle off at
  high damping; conservative/steady c0/c1 stay attached, 9/9 at every level).
- Optimal-candidate **switch rate 2/3 targets (0.667)**; pairwise **rank-reversal 0.170–0.178** — under the
  full frozen utility only. These are **landscape statistics, not decision value**.

### 3. Selection — only beats a WEAK baseline; no decision value
- State-aware selection (B2) beats the **no-history B1** baseline (regret **0.000 vs 0.026**), but only
  **ties the robust generalist** "always `c1_steady`" (regret **0.0007 ≈ oracle**).
- **VSI (value of state information) ≈ +0.00059** under the frozen utility `U = p − 1.0·err − 0.02·time`
  — < 0.1 % of the ~0.80 utility scale. Independently reproduced: A self-check +0.0006, B offline +0.00059,
  C audit +0.00067. VSI is **0.00000** under success-only and success+error utilities.
- **Robust generalist makes decision value ≈ 0**: `c1_steady` succeeds **27/27** across all damping and is
  the state-agnostic optimum (best or within ~0.001 U) at every state — even the **oracle** upper bound on
  selection value is ~0.
- **Net value of probing is negative**: once the 3 probes' execution time is charged, net VOI < 0
  (K = 1 ≈ −0.19); probing to enable selection is strictly net-negative here.

### 4. Replicates are technical repeats — NOT independent samples
- The generator applies **no per-replicate seed, no randomized reset, no sensor/actuator noise, no domain
  randomization**. Replicates `r = 0,1,2` at a fixed damping differ only by label.
- Empirically within-replicate SD of `task_outcome_error` ≈ **6·10⁻⁴** (PhysX float nondeterminism),
  **1–2 orders of magnitude below** the cross-damping signal; **replicate noise never flips a success
  label**. Effective independent n over the hidden state is **≈ 3 (damping levels), not 9 sessions**.

### 5. Integrity — clean (no leakage, matched bank verified)
- θ is a **pure function of `candidate_id`** (0 damping-dependent θ); each candidate id appears exactly 3×
  at each damping; bank sha pinned on every episode; `is_matched_bank: true`.
- **No hidden-state leakage**: identical resets → `x` carries no damping; legal history = same-session prior
  probes only, with a `damping/secret/hidden` key filter; poison-injection leakage tests reject correctly.
- Tests (integration worktree, all green): `pytest tests/offline_v2/` **34 passed**; `pytest tests/`
  **34 passed**; matched-candidate-bank test **PASS**; history-leakage test **PASS**.

## Verdict — MODIFY (converged independently by A, B, C)
Not STOP (science sound, D1–D4 hold, no leakage, framework valid) and not GO (the decision-value core —
"does knowing the state change which plan you pick?" — is **null under a defensible frozen utility** because
a robust generalist exists). The honest, publishable contribution: **calibration buys prediction, not
selection, when a robust generalist policy is near-optimal at every state.**

**Binding guardrail (all three streams agree):** do **not** manufacture selection value by removing the
robust generalist or raising λ_time *after* observing the null — that fits the experiment to the desired
conclusion. Keep the utility frozen and λ a-priori. (B's sensitivity grid: even λ_time = 0.5 yields VSI
only 0.067 while `c1_steady` stays near-best.)
