## 3. Raw optimal-candidate switch + state-aware vs state-agnostic gap
- **Optimal-candidate SWITCH across damping: 2/3 targets** change their best archetype.
  - T012: c1_steady → c1_steady → c1_steady (no switch)
  - T020: **c2_balanced → c1_steady → c1_steady**
  - T028: **c2_balanced → c1_steady → c1_steady**
- **State-aware vs state-agnostic raw utility gap: mean = +0.0006** over 9 (damping, target) cells.

**Honest interpretation.** The argmax *does* switch and the landscape reorders violently, but the raw
*selection* payoff is negligible because a **robust generalist exists**: `c1_steady` succeeds **27/27**
across every damping level and is within ~0.001 of the best archetype at low damping too. Under the frozen
utility, speed is barely rewarded (λ_time = 0.02), so the low-damping aggressive candidates never beat the
robust `c1_steady` by enough to make knowing the state pay. **In this bank, a state-agnostic policy that
always picks `c1_steady` is nearly as good as an oracle state-aware selector** — even though damping
massively changes the candidate landscape.

This is a real finding, not a null: it isolates the condition under which deployment-state calibration
helps *selection* (as opposed to *prediction*, which the probes clearly support — §4). Calibration pays
for selection only when the bank has **no single robust generalist** and/or the utility rewards the axis
(speed) on which the state-optimal candidate actually differs.

## 4. Signal available to Claude B (prediction side)
Probes strongly encode the hidden state (mean over 9 probes/level): success **9/9 → 6/9 → 3/9**; mean final
**0.215 → 0.152 → 0.095**; mean PULL duration **0.92 → 1.52 → 1.84 s**. Probe P1 (aggressive pull) final
position spreads **0.266 → 0.080 → 0.039** (spread 0.227) — a clean, monotonic hidden-state discriminator;
P2 (fine step) is damping-invariant (spread 0.001). So a probe-history model can recover damping; the open
question the formal run must answer is whether that recovery reduces *selection regret* — which requires a
bank/utility without a robust generalist (below).

## 5. Recommendations for the formal run (design notes — NOT applied here)
The frozen bank is left untouched (no post-hoc tuning to the outcome). For the formal stage, to make the
selection-regret payoff measurable:
1. **Remove the robust generalist**: design the bank so the high-damping-safe candidate is *meaningfully
   worse* at low damping (e.g. a candidate that under-pulls and misses the far target at D=3 but is the
   only survivor at D=40), so no single θ is near-optimal at all states.
2. **Reward the differing axis**: raise λ_time (or add an explicit speed term) so the low-damping-optimal
   (fast/aggressive) genuinely beats the robust-but-slow candidate — otherwise argmax switches are
   utility-neutral as seen here.
3. Keep the matched-bank machinery, 3 targets, and ≥3 replicates (this run proves they work and give 9
   clean matched groups).
