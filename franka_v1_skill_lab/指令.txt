提高控制精度/频率（遥操作发飘/滞后时调这几个；test 与 collect 入口都支持）：
  --control_hz 50      控制频率，换算 env decimation=round(100/hz)。底层任务才 20Hz（卡）；50→50Hz，100→100Hz。最关键。
  --arm_stiffness 400  Franka 关节 PD 刚度（默认任务只有 80=软，追不准）；400=HIGH_PD，跟踪紧。
  --arm_damping 80     关节 PD 阻尼。
  --max_joint_vel 4.0  关节最大角速度(rad/s)，per-step 限幅=vel/control_hz；手快跟不上就调大。
  --lowpass_alpha 0.5  GELLO 读数 EMA（越大越跟手/越少滞后，1.0=不平滑）。
  --gello_hz 100       真实 GELLO 串口读取频率。
  # 先用 drive_isaac 试手感（不录制）：--control_hz 100 --arm_stiffness 600 --lowpass_alpha 0.7
  # 代价：刚度越大撞击越硬；vel/alpha 越大越跟手但安全平滑越少；频率越高越吃实时性（单环境、headless 或轻量 GUI）。

采集时键盘控制（GUI；headless/mock 走自动脚本，无需按键）：
  SPACE：暂停 / 恢复 recording
  S：标记当前 episode 成功并保存
  F：标记失败（--save_failed 则存到 failed 文件，否则丢弃）
  D：丢弃当前 episode
  R：重置当前 episode（丢弃 + 重置场景）
  N：进入下一个 episode
  E：紧急停止 / 冻结关节目标（再按一次解除）
  H：回到 home / hold 姿态
  Q：安全退出采集
  1-6：选择技能类型（grasp/place/open_drawer/close_drawer/open_door/close_door）

转换采集数据到 pi0.5 / LeRobot（[ready] normalized 必出；LeRobot best-effort）：
python projects/franka_v1_skill_lab/pi05_training/adapters/skill_demo_to_lerobot.py \

  --output projects/franka_v1_skill_lab/data/lerobot/franka_v1_skill_pi05 \
  --task_config projects/franka_v1_skill_lab/configs/teleop_tasks.yaml

注意：
- mock 与真实 GELLO 都已端到端验证（真机：实读 /dev/ttyUSB0，机器人安全跟随并录制）。
- GUI 下 gello 默认走键盘控制：ENTER 开始录制，S 保存，Q 退出（headless 自动录 N 步后退出）。
- 机器人在 PREPARE/RECORDING 状态跟随设备；SPACE 暂停 / E 急停时冻结不动。
- GELLO 标定在 teleop_collection/gello/configs/gello_franka.yaml；机器人乱跳就重标定。
- 只有 success episode 进训练集；failed/discarded 不会混入（转换默认只取 success）。

末端相机 / FoundationPose RGB-D / VLA RGB
============================================================

V1 共用场景固定挂三个相机（sensors/d435/d435_config.py 是唯一来源）：
- vla_front_static         ：固定第三人称 RGB 256x256 -> LeRobot/π0.5 `image`（主视角）
    挂在 {ENV_REGEX_NS}/vla_front_static（env 根下，静态，不随手腕动）
    位姿复用 IsaacLab table_cam：pos(1.0,0,0.4) ros，正对 Franka+cube 工作区，不是俯视
- vla_libero_eye_in_hand   ：手腕 RGB 128x128/224x224 -> LeRobot/π0.5 `wrist_image`
    挂在 {ENV_REGEX_NS}/Robot/panda_hand/，参考 robosuite/LIBERO robot0_eye_in_hand
- foundationpose_d435_rgbd ：手腕 RGB+depth 640x480 -> FoundationPose（与 wrist 同位姿）
- LeRobot 映射：image <- vla_front_static；wrist_image <- vla_libero_eye_in_hand
  （pi05_isaacsim_baseline/configs/dataset_mapping_isaaclab_franka.yaml，image_resize 256x256）
- attach_wrist_cameras(env_cfg) 是唯一把三个相机加进场景的入口，layout/状态机/遥操作都调它
- registry scene_v1_registry.json 的 sensors 里记录这三个相机
- D435_Body 外形 mesh 默认隐藏（纯视觉、无碰撞）；要看用 --show_camera_body
- 相机渲染需要 --enable_cameras；FoundationPose 相机若没渲染 depth，capture() 会明确报错
  "Depth output is not available for foundationpose_d435_rgbd."，不会静默返回 None
